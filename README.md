# FarmRak: ฟาร์มรักษ์

แอป Android (Kotlin) สำหรับระบบรดน้ำ/ให้ปุ๋ยอัตโนมัติด้วยบอร์ด ESP32 ออกแบบมาสำหรับเกษตรกรไทย เน้นใช้งานง่าย (ผู้สูงอายุใช้ได้) และ**ทำงานได้แบบ local ล้วนๆ ไม่ต้องพึ่งอินเทอร์เน็ต**

โครงการภายใต้ Community Engagement Program ปีที่ 2 โรงเรียนมหิดลวิทยานุสรณ์ (รายละเอียดอยู่ในแอป หน้า "ตั้งค่า" > "เกี่ยวกับแอป")

---

## ภาพรวมสถาปัตยกรรม

```
[มือถือ] --- ต่อ WiFi ตรง ---> [ESP32 (Soft-AP)] --- ต่อสาย ---> [เซนเซอร์ + รีเลย์]
```

ESP32 เปิดตัวเองเป็น **WiFi Access Point** (ชื่อ "FarmRak-Board") มือถือต่อ WiFi เข้าไปโดยตรงผ่านการตั้งค่าระบบของ Android แล้วแอปคุยกับบอร์ดผ่าน **HTTP ธรรมดา** ในเครือข่ายเดียวกัน:

| ทิศทาง | Endpoint | หน้าที่ |
|---|---|---|
| แอป → บอร์ด | `GET /api/status` | อ่านค่าความชื้น/pH/สถานะปั๊ม-ปุ๋ยปัจจุบัน |
| แอป → บอร์ด | `POST /api/command` | สั่งเปิด/ปิดปั๊ม, โหมดอัตโนมัติ, ปรับเกณฑ์ |

**ไม่มี broker, ไม่มีคลาวด์, ไม่มีบัญชีต้องสมัคร ไม่มีข้อมูลออกนอกพื้นที่เลย** — ข้อแลกเปลี่ยนคือใช้งานได้เฉพาะตอนมือถืออยู่ในระยะ WiFi ของบอร์ดเท่านั้น (ดูรายละเอียดที่ `FarmRak_ESP32_Local/README_LOCAL_SETUP.md`)

> โปรเจกต์เคยใช้สถาปัตยกรรม MQTT ผ่านคลาวด์มาก่อน (โฟลเดอร์ `FarmRak_ESP32/` เก็บเวอร์ชันนั้นไว้เผื่ออนาคตอยากกลับไปทำเวอร์ชันที่ดูข้อมูลจากนอกพื้นที่ได้) แต่**เวอร์ชันที่ใช้งานจริงตอนนี้คือ Local/HTTP** ทั้งหมด ไฟล์ที่เกี่ยวกับ MQTT (HiveMQ client) ถูกลบออกจากแอปแล้ว

## ฟีเจอร์หลัก

### หน้าหลัก (Dashboard)
- การ์ดความชื้นในดิน + ค่า pH แบบตัวเลขใหญ่ อ่านง่าย พร้อมคำอธิบายสถานะ
- แสดง **"--" สีแดง** เมื่อยังไม่มีข้อมูลจริง/ขาดการเชื่อมต่อ (ไม่มีทางเห็นค่าตัวเลขปลอมค้างอยู่)
- สถานะปั๊มน้ำ/ระบบให้ปุ๋ย: `กำลังทำงาน` / `ปิดอยู่` / `ไม่ได้เชื่อมต่อ` (สีส้ม)
- สวิตช์โหมดอัตโนมัติ: เขียว=เปิด, แดง=ปิด
- ปุ่มรดน้ำ/ให้ปุ๋ยด้วยตนเอง (ใช้ได้เมื่อปิดโหมดอัตโนมัติ) มี Snackbar แจ้งผลจริงว่าส่งคำสั่งถึงบอร์ดสำเร็จหรือไม่
- จุดสถานะบอร์ด (เขียว/เหลือง/แดง) + ปุ่ม "?" เปิดคู่มือเชื่อมต่อ 4 ขั้นตอน (โผล่เฉพาะตอนไม่ได้เชื่อมต่อ)
- **แสดงเวลาบนบอร์ดชัดเจน** ("เวลาบนบอร์ด: HH:mm:ss น.") พร้อมปุ่ม **"ซิงค์เวลา"** ให้กดส่งเวลามือถือไปตั้งค่าบอร์ดได้ตลอดเวลา — ข้อความจะเปลี่ยนเป็นสีส้มถ้าตรวจพบว่าเวลาบอร์ดกับมือถือต่างกันเกิน 5 วินาที
- **ตัวเลข pH เปลี่ยนสีตามสถานะ** — แดง = เป็นกรดเกินไป, ส้ม = เป็นด่างเกินไป, ดำ = อยู่ในเกณฑ์ที่ตั้งไว้ (เน้นเฉพาะ pH เพราะเป็นค่าที่ไม่มีระบบใดแก้ให้อัตโนมัติ ต่างจากความชื้นที่ปั๊มจัดการเองอยู่แล้ว)

### ประวัติ (History)
- กราฟเส้นความชื้น/pH ย้อนหลัง **พร้อมป้ายเวลากำกับด้านล่าง** (เริ่มต้น/กลาง/ล่าสุด) — เก็บจุดข้อมูลทุก 5 นาที ย้อนหลังได้ถึง 8 ชั่วโมง (ไม่ใช่แค่ทุก poll เหมือนเดิมที่เห็นได้แค่ ~2 นาที)
- log เหตุการณ์ — บันทึกแบบ **edge-triggered** คือเขียนเฉพาะตอน *เปลี่ยนสถานะ* เท่านั้น (เริ่ม/หยุดรดน้ำ, เริ่ม/จบให้ปุ๋ย, pH ออกนอกช่วง/กลับเข้าช่วง) พร้อมระบุว่าเป็นระบบอัตโนมัติหรือสั่งเอง
- **ปุ่ม "ล้าง log"** ล้างประวัติทั้งหมดได้เอง (มีถามยืนยันก่อนเสมอ) + **ลบ log ที่เก่าเกิน 7 วันทิ้งอัตโนมัติ**
- เก็บใน memory ระหว่าง session เท่านั้น (ดูข้อจำกัดด้านล่าง)

### ตำราพืช (Plants)
- **45 พืชสวนครัวไทยสำเร็จรูป** ครอบคลุม 7 หมวด: สมุนไพร, ผักใบ, ผักผล, ไม้เลื้อย, พืชหัว, ไม้ยืนต้น, **ดอกไม้** (หมวดใหม่) — ข้อมูล pH/ความชื้น/ปุ๋ยแนะนำ + บรรณานุกรมครบทุกชนิด
- **เรียงตามลำดับตัวอักษรไทย ก-ฮ** ด้วย `Collator` (ไม่ใช่เรียงตาม Unicode ตรงๆ ซึ่งจะทำให้คำที่มีสระนำหน้าอย่าง เ-/แ-/โ-/ใ-/ไ- เรียงผิดตำแหน่ง)
- ค้นหาได้ทั้งชื่อไทย/ชื่อวิทยาศาสตร์
- **เพิ่มพืชของตัวเองได้ไม่จำกัด** พร้อมรูปถ่าย, แก้ไข/ลบได้ (พืชสำเร็จรูปแก้ไม่ได้) — เลือกหมวด "ดอกไม้" ให้พืชที่เพิ่มเองได้ด้วย
- Validation ครบก่อนบันทึก + feedback ชัดเจนถ้าบันทึกไม่สำเร็จ
- **หมายเหตุเรื่องรูป**: 15 พืชแรก (ที่ผู้ใช้ส่งรูปมาให้ตอนแรก) มีรูปถ่ายจริง ส่วน 30 พืชที่เพิ่มใหม่รอบนี้ยังไม่มีรูปถ่ายจริง จะแสดงเป็นไอคอนตามหมวดแทน (ระบบ fallback ที่มีอยู่แล้วจัดการให้อัตโนมัติ) — ส่งรูปมาเพิ่มได้ทีหลังตามที่สะดวก

### ตั้งค่า (Settings)
จัดกลุ่มชัดเจนเป็น 3 หมวด (เรียงจากบนลงล่าง): **ข้อมูลส่วนตัว** → **ตั้งค่าระบบอัตโนมัติ** → **ตั้งค่าบอร์ด** (มีเส้นสีบอกหมวดกำกับแต่ละกลุ่ม) — ระบบอัตโนมัติขึ้นก่อนบอร์ด เพราะเป็นสิ่งที่เกษตรกรต้องปรับบ่อยกว่า:

- **ข้อมูลส่วนตัว**: ชื่อ/อาชีพ/ประสบการณ์/รูป (dropdown ไม่ใช่พิมพ์อิสระ) — ปุ่มบันทึกของตัวเอง
- **ตั้งค่าระบบอัตโนมัติ**: เกณฑ์ความชื้น/pH (ปุ่มบันทึกแยกเฉพาะกลุ่มนี้) + ตารางให้ปุ๋ยอัตโนมัติ (กำหนดเวลา+ระยะเวลาได้หลายช่วง แอปส่งไปเก็บที่บอร์ดเอง บอร์ดจึงให้ปุ๋ยตรงเวลาได้แม้ปิดแอป/ตัด WiFi ไปแล้ว — ปุ๋ยไม่ผูกกับค่า pH อีกต่อไป เพราะการให้ปุ๋ยไม่ได้แก้ค่า pH ของดิน)
- **ตั้งค่าบอร์ด**: ที่อยู่ IP บอร์ด (ปุ่มบันทึกแยกเฉพาะกลุ่มนี้) + ตั้งค่า WiFi บ้าน/ไร่ (บอร์ดเชื่อมต่อได้ทั้ง WiFi ของตัวเองและ WiFi บ้าน/ไร่พร้อมกัน ตั้งค่าผ่านแอปได้เลย ไม่ต้องเสียบสาย/คอมไพล์ใหม่)
- ปุ่ม "วิธีใช้แอป" เปิดทัวร์แนะนำซ้ำได้ตลอด (อัปเดตเป็น 12 ขั้นตอน ครอบคลุมฟีเจอร์ใหม่ทั้งหมด รวมถึงสอนตั้งค่ารดน้ำอัตโนมัติโดยเฉพาะ) — ทัวร์จะเลื่อนจอให้ target มองเห็นเต็มก่อนเสมอ (สำคัญกับหน้าตั้งค่าที่ยาว) และ fallback เป็นกล่องข้อความกลางจอถ้าจุดที่จะชี้ยังไม่แสดงผล (เช่น ปุ่มซิงค์เวลาตอนยังไม่เชื่อมต่อบอร์ด)
- **"เกี่ยวกับโครงการ"** (พับ/กางได้) — ออกแบบใหม่ให้น่าอ่าน: ประโยคเปิดตัวหนาใหญ่, การ์ดตัวเลขสถิติสำคัญ 3 ใบ (12 ล้านแรงงาน / 26% เข้าถึงชลประทาน / ลดน้ำ 30%), แบ่งเนื้อหาเป็น 3 หัวข้อย่อย (ปัญหาที่เราเห็น → ช่องว่างที่ยังไม่มีใครแก้ → สิ่งที่เราทำ), แถบรูปพืช, รายชื่อทีม, โลโก้

### ระบบแจ้งเตือน + Foreground Service
แจ้งเตือน 4 แบบ (เชื่อมต่อแล้ว/ตัดการเชื่อมต่อ/pH ผิดปกติ/ความชื้นต่ำ) ทำงานต่อได้แม้แอปอยู่เบื้องหลัง ผ่าน `BoardMonitorService` ที่ออกแบบให้ประหยัดแบต (poll ช้าลงเหลือทุก 20s ตอนไม่ได้เปิดแอปอยู่ และสลับกับ ViewModel แบบไม่ให้ poll ซ้อนกันเด็ดขาด)

### วิธีใช้ (Tutorial)
ทัวร์แนะนำสไตล์สปอตไลท์ (พื้นมืด + วงกลมสว่างไล่ทีละจุด) พาไปทั้ง 4 แท็บ 8 ขั้นตอน มีปุ่มย้อนกลับ/ถัดไป/ข้าม ถามตอนแรกเข้าว่าเคยใช้มาก่อนไหม ถ้าไม่เคยจะเริ่มทัวร์ให้อัตโนมัติ

## อัปเดตล่าสุด (แก้ปัญหา "gradle-wrapper.properties not found")

พบว่าโปรเจกต์ที่ส่งให้ก่อนหน้านี้**ขาดไฟล์ Gradle Wrapper ไปทั้งชุด** (`gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`, `gradle-wrapper.properties`) — เป็นความผิดพลาดตั้งแต่ตอนสร้างโปรเจกต์ครั้งแรก ทำให้ Android Studio หา Gradle version ที่ถูกต้องไม่เจอ (น่าจะเป็นต้นเหตุของปัญหา "Invalid Gradle JDK" ที่เจอก่อนหน้านี้ด้วย)

**แก้แล้ว**: เพิ่มไฟล์ครบชุด กำหนดให้ใช้ **Gradle 8.7** (เข้ากันได้กับ AGP 8.4.0 และ Java 17 ที่โปรเจกต์นี้ใช้อยู่) ทั้งแอปจริงและเดโม — เปิดโปรเจกต์ใหม่แล้ว Android Studio จะดาวน์โหลด Gradle 8.7 ให้เองอัตโนมัติตอน sync ครั้งแรก (ต้องมีอินเทอร์เน็ตตอนนั้นครั้งเดียว)

## วิธีเปิดโปรเจกต์ (ฝั่งแอป)

1. เปิด Android Studio → **Open** → เลือกโฟลเดอร์ `FarmPulse`
2. รอ Gradle sync (ครั้งแรกต้องมีอินเทอร์เน็ตเพื่อโหลด dependency — หลังจากนั้นตัวแอปไม่ต้องพึ่งเน็ตแล้ว)
3. เชื่อมมือถือ/เปิด emulator แล้วกด Run ▶ — เปิดแอปได้เลยแม้ยังไม่มีบอร์ดจริง (จะเห็นสถานะ "ไม่ได้เชื่อมต่อ" ทุกจุด ซึ่งถูกต้องแล้ว)

## วิธีตั้งค่าบอร์ดจริง

ดูคู่มือฉบับเต็มที่ **`FarmRak_ESP32_Local/README_LOCAL_SETUP.md`** สรุปสั้นๆ:
1. ต่อสายเซนเซอร์/รีเลย์ตามตารางในคู่มือ
2. Flash `FarmRak_ESP32_Local.ino` ผ่าน Arduino IDE (ต้องมี ESP32 board support + ไลบรารี ArduinoJson)
3. คาลิเบรตเซนเซอร์ผ่าน Serial Monitor
4. ต่อ WiFi มือถือไปที่ "FarmRak-Board"
5. กรอก IP บอร์ด (ปกติ `192.168.4.1`) ในหน้าตั้งค่าของแอป

## ข้อจำกัดที่ทราบอยู่แล้ว (สำหรับนักพัฒนาต่อ)

| จุด | รายละเอียด |
|---|---|
| **ไม่มีการเข้าถึงจากนอกพื้นที่แบบไร้ขีดจำกัด** | เชื่อมต่อ WiFi บ้าน/ไร่ได้แล้ว (ขยายระยะให้ครอบคลุมทั้งพื้นที่ WiFi นั้น) แต่ยังไม่ใช่การเข้าถึงจากที่ไหนก็ได้ในโลก — อันนั้นต้องมีสถาปัตยกรรมคลาวด์แยกต่างหาก |
| **ประวัติเก็บใน memory เท่านั้น** | `SensorViewModel` เก็บ log/กราฟย้อนหลังใน `MutableLiveData` — ปิดแอปแล้วหาย ยังไม่ได้ทำ Room database ฝั่งแอป หรือ log บนบอร์ดเอง (LittleFS) |
| **แจ้งเตือนไม่ทำงาน 100% ถ้าปัดปิดแอป** | Foreground Service จะหยุดถ้าผู้ใช้ swipe ปิดแอปออกจาก recent apps โดยตรง (ตั้งใจออกแบบให้เป็นแบบนี้เพื่อประหยัดแบต) |
| **HTTP ไม่เข้ารหัส** | คุยกับบอร์ดผ่าน HTTP ธรรมดา (ไม่ใช่ HTTPS) เพราะเป็นเครือข่ายปิดของตัวเองอยู่แล้ว (Soft-AP) ความเสี่ยงต่ำ แต่ควรรู้ไว้ |
| **ไม่รองรับหลายบอร์ด** | ออกแบบมาสำหรับบอร์ดเดียวต่อแอป 1 ชุด ถ้าจะรองรับหลายแปลง/หลายบอร์ดต้องปรับ `SettingsRepository` ให้เก็บเป็น list |
| **เวลาบอร์ดต้องรอ sync จากแอปก่อนถึงจะแม่น** | ใช้วิธี sync เวลาจากมือถือ (ฟรี ไม่ต้องมี RTC) แต่ถ้าไฟดับแล้วยังไม่มีใครมาเชื่อมต่อ เวลาจะรีเซ็ตชั่วคราวจนกว่าจะมีแอปมา sync ใหม่ — ถ้าต้องการเวลาแม่นแม้ไฟดับนาน ต้องเพิ่มโมดูล RTC (เช่น DS3231) |

## แผนพัฒนาต่อ (แนะนำสำหรับเวอร์ชันถัดไป)

- [ ] **บันทึก log เหตุการณ์บนบอร์ดเอง** (LittleFS ในตัว ESP32 ไม่ต้องซื้ออุปกรณ์เพิ่ม) แล้วให้แอปดึงมาสมทบกับประวัติทุกครั้งที่เชื่อมต่อสำเร็จ — คุยรายละเอียดไว้แล้ว ยังไม่ได้ลงมือทำ
- [ ] **Room database** สำหรับเก็บประวัติ/log ถาวรฝั่งแอป แทนที่จะหายเมื่อปิดแอป
- [ ] **วิซาร์ดเชื่อมต่อบอร์ดในแอป** — หน้าจอทดสอบการเชื่อมต่อแบบเรียลไทม์ (✅/❌ ขณะตั้งค่า) สำหรับการจับคู่ครั้งแรกกับ WiFi ของบอร์ดเอง (แยกจากการตั้งค่า WiFi บ้าน/ไร่ที่ทำเสร็จแล้ว)
- [ ] **โมดูล RTC (เช่น DS3231)** ถ้าต้องการเวลาแม่นยำแม้ไฟดับนานโดยไม่ต้องรอแอปมา sync ใหม่
- [ ] **รองรับหลายบอร์ด/หลายแปลง** ในบัญชีเดียว
- [ ] ลบไฟล์ `SoilMoistureView.kt`/`PhGaugeView.kt` ที่ไม่ได้ใช้แล้ว (หรือคงไว้ถ้ามีแผนกลับไปใช้ดีไซน์แบบมีหน้าปัด)
- [ ] เพิ่ม root CA certificate validation ให้ MQTT firmware เดิม (`FarmRak_ESP32/`) ถ้าจะกลับไปใช้เวอร์ชันนั้นในอนาคต (ตอนนี้ใช้ `setInsecure()`)
